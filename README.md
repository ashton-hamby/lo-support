# Ashton Hamby | LO Support

Personal website for Ashton Hamby, Loan Partner, offering LO Support services, built as a static site for free GitHub Pages hosting.

## Preview and publishing

Open `index.html` locally to preview. To publish, open the repository **Settings → Pages**, select **Deploy from a branch**, choose **main** and **/(root)**, and save. The expected URL is https://ashton-hamby.github.io/lo-support/ after deployment.

## Before launch

- Confirm NEXA compliance and required licensing/company disclosures.
- Review branding permissions before public use of UMortgage-inspired design.
- Replace the contact placeholder with an approved contact method.
- Confirm service descriptions, lender references, and any compensation language.
- Add approved resources; do not commit borrower information, passwords, internal SOPs, or other sensitive data to this public repository.

The LO Resources section is **public** and is not an authenticated portal. Confidential documents should be hosted separately in approved systems with access controls.
