Qualification Review & Pre-Approval

Loan Partner SOP: document validation through LO handoff.

1. Validate Client Needs

  1. Review each uploaded document for completeness, accuracy, and whether it satisfies the request.
  2. Approve or disapprove individual documents in Arive.
  3. Accept each complete Client Need task. Reject incomplete Needs and update descriptions to clarify missing items.
  4. Finish reviewing all Needs before sending one consolidated request.
  5. Return outstanding items to the Document Follow-Up SOP.

Begin income calculations as soon as all requested income documentation is received and validated, even if other Needs remain outstanding.

2. Income Review and Calculation

  1. Identify each income source separately for each borrower.
  2. For non-variable W-2 base pay (salary or consistent hourly hours), calculate in Arive and confirm YTD base earnings meet or exceed expectations; investigate shortfalls.
  3. For variable base pay (fluctuating hourly hours), overtime, bonus, and commission, follow the program-specific tool guide below.
  4. For self-employment, use MGIC and/or UWM; agency calculators are additional resources as appropriate.
  5. Save completed external worksheets/results in Arive and enter each qualifying income source separately.

3. Asset Review

  1. Review all bank, investment, retirement, and gift fund documentation together.
  2. Verify ownership, dates, completeness, and available balances.
  3. Review transactions; note large deposits and request supporting source documentation.
  4. Update asset balances in Arive and mark Verified and/or Liquid as applicable.
  5. Finish reviewing all asset statements before sending one consolidated request for additional documentation.

4. Application Verification

  1. Verify IDs match the application.
  2. Verify Real Estate Owned information.
  3. Cross-reference credit report with liabilities and declarations again.
  4. Correct Arive directly whenever supporting documentation establishes the accurate information; request clarification only for unresolved issues.

5. Product Selection, Pricing, and Fees

  1. Choose the appropriate program based on qualifications before pricing.
  2. Use Arive's pricing engine to select a lender based on pricing and guideline fit.
  3. Apply pricing to the loan file.
  4. Run SmartFees and review the entire Fees screen.
  5. Verify processing, credit report, appraisal, and appraisal re-inspection fees.
  6. Enter estimated property taxes and homeowners insurance; correct inaccuracies.

6. DTI, Hard Pull, and AUS Decision

  1. Review front-end and back-end DTI after fees are complete.
  2. For Conventional: credit score above 680 and green Arive DTI may proceed without AUS at this stage; otherwise recommend a hard pull and AUS.
  3. For FHA/VA: credit score 680+ and green DTI may proceed without AUS at this stage. If DTI is not green, recommend hard pull and AUS. If score is below 680, assess manual underwriting eligibility, document why, and advise the LO.
  4. The LO decides whether to order a hard credit pull.
  5. When approved, create an Arive Client Need with the SmartPay payment link. After payment, import the hard credit report and run AUS.
  6. Review AUS findings and requirements before pre-approval.
AUS findingAction
Approve/Eligible or Accept/EligibleReview findings and proceed if supported.
Refer, manual underwriting eligibleDocument manual underwriting requirements and pre-approve if supported.
Refer, manual underwriting not eligibleDocument why and send findings to LO for borrower conversation.
Caution or IneligibleInvestigate and document reason; LO handles borrower conversation.

These are internal screening criteria, not agency approval rules. Pre-approval without AUS is not AUS approval. Confirm applicable lender, investor, and program requirements.

7. Pre-Approval and LO Handoff

  1. When supported, mark Pre-Approved in Arive without notifying the borrower.
  2. Add a Status Note with qualification details, recommended terms, and AUS/manual underwriting status.
  3. Assign the LO a task to schedule a pre-approval consultation and issue the pre-approval letter.
  4. Do not generate the letter yourself.
  5. Assign yourself an Update Pre-Approval task due in 90 days.
