90-Day Pre-Approval Expiration

Return expired pre-approvals to Qualification and request direction from the Loan Officer.

Procedure

  1. At the 90-day pre-approval update task due date, open the loan file in Arive.
  2. Change the status from Pre-Approved to Qualification.
  3. Add an Arive Status Note documenting that the pre-approval has expired.
  4. Ask the LO to re-engage the borrower and advise whether updated documentation should be requested to reissue the pre-approval.
  5. Do not automatically request updated documents. Wait for the LO's direction.
